# AgenTrust Develop for Good
 
Student volunteer work to help companies use [AgenTrust](https://agentrust-io.com) safely.
 
AgenTrust is an open-source ecosystem for governing AI agents in a way that can be verified. This repo holds the guides, demos and documentation that student developers are building through Develop for Good, with XRSI (X Reality Safety Intelligence).
 
## What we are building
 
| What | How many | What it is |
|---|---|---|
| Rule guides | 4 | One guide each for ISO 42001, the EU AI Act (Article 50), GDPR and NIST |
| Demos | 4 | A small working program for each guide |
| Getting-started guide | 1 | The "start here" page. A newcomer should get AgenTrust working in 30 minutes |
| Volunteer docs | 1 set | Setup docs for new volunteers, and a handoff page for the team that continues the project |
 
## Where things are

## How to take part
 
1. Read [CONTRIBUTING.md](CONTRIBUTING.md). It explains how to pick a task, make changes and send them for review.
2. Find your task in the **Issues** tab, or on the project board.
3. Work on your own branch and open a pull request. Your review partner will check it.
Please follow our [Code of Conduct](CODE_OF_CONDUCT.md).
